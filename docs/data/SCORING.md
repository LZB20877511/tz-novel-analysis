# 评分量表（1–10 分，六维加权，可复核）

> 目的：让"排序"有依据、可复现、可对比。**禁止**给一个没有分项理由的总分。
> 每个维度分必须附带：分数 + 一句依据 + 证据标签（`真实正文` / `章节标题` / `外部共识` / `不可得`）。

## 一、六维量表

### 1. 文笔文风 `W`（权重 0.25）
| 分档 | 特征 |
|---|---|
| 9–10 | 句法有个人印记，意象独到，长短句节奏受控，白描即传神，几乎无废字 |
| 7–8 | 表达准确流畅，偶有亮句，叙事节奏稳，有可辨识的文风 |
| 5–6 | 通顺但平，功能性强（把事说清楚），缺记忆点；书面感与口语感混杂 |
| 3–4 | 句式单调重复，形容词堆砌，副词滥用（"猛地""不禁"高频） |
| 1–2 | 病句频出、主谓混乱、流水账 |

**具体可数指标（从真实正文算，别凭感觉）**：
- 平均句长、句长标准差（标准差小 = 节奏平）
- 对话句占比（过高常显得单薄，过低显得闷）
- 高频重复词 top5（"忽然/猛地/瞬间"等 → 手法偷懒信号）
- 每千字形容词/副词密度（MDA 类指标）
- 段落平均长度（网文常 1–3 行为一段，属体裁常态，**不因此扣分**）

### 2. 人物描写 `C`（权重 0.20）
| 分档 | 特征 |
|---|---|
| 9–10 | 主角与配角都有独立动机与成长弧，行为自洽，能通过"说话方式"辨人 |
| 7–8 | 主角立体，2–3 个配角有记忆点，动机基本自洽 |
| 5–6 | 主角靠标签立住（冷酷/腹黑/天才），配角功能性（推动剧情/送东西） |
| 3–4 | 全员工具人，性格靠旁白直接宣布，而非行为呈现 |
| 1–2 | 人物前后矛盾，人设崩坏 |

**考察点**：是否有配角在离开主角视线后仍有自主行动；反派是否有可理解的理由；
人物是否"只靠对话标签可辨识"；有无强行降智。

### 3. 事物描写 `T`（权重 0.15）
即"事物/场景/设定/物品"的描写功力（用户口语中的"事物描写"）。
| 分档 | 特征 |
|---|---|
| 9–10 | 场景有层次与气味感，设定自洽且被"用出来"而非说明书式解释，物件能承载情绪 |
| 7–8 | 场景清晰有画面，设定基本自洽，偶有惊艳细节 |
| 5–6 | 描写合格但套路，"金碧辉煌的大殿"式模板 |
| 3–4 | 设定前后矛盾，需要读者自己脑补 |
| 1–2 | 几乎无环境描写或纯信息倾倒 |

**考察点**：五感使用（是否只有视觉）；设定解释是"融进情节"还是"停更讲设定"；
名词密度（专有名词过密 = 阅读负担）。

### 4. 感情描写 `E`（权重 0.15）
覆盖亲情/友情/爱情/信念/牺牲等全部情感线，**不只是恋爱**。
| 分档 | 特征 |
|---|---|
| 9–10 | 情绪靠细节与留白累积，克制但有后劲；读者会自己哭 |
| 7–8 | 情感线成立，有 1–2 个真正打动人的节点 |
| 5–6 | 靠事件强推（死人就悲伤），情感转变缺少铺垫 |
| 3–4 | 情感线工具化，恋爱为发糖而发糖 |
| 1–2 | 情感表达油腻/尬/强行煽情 |

**考察点**：情绪是否"被写出来"还是"被说出来"；有无为了虐而虐；感情推进与剧情推进是否互为因果。

### 5. 情节节奏与逻辑 `P`（权重 0.15）
| 分档 | 特征 |
|---|---|
| 9–10 | 结构清晰、伏笔回收干净、张弛有度，读完想立刻重看找伏笔 |
| 7–8 | 主线清晰，少数支线拖沓，逻辑基本自洽 |
| 5–6 | 前期拖/中期水/后期崩 占其一；有明显巧合推动 |
| 3–4 | 逻辑硬伤多，靠降智推进 |
| 1–2 | 不知所云 |

**可数指标**：章节数、总字数、分卷数、每卷章数（判断结构是否均衡）；
章节标题的"信息密度"（标题=剧情转折点 vs 标题="新的开始"这类无信息标题）。

### 6. 阅读体验 / 沉浸与技术完成度 `X`（权重 0.10）
含：上手门槛、沉浸感、设定学习成本、错别字/文句错误、爽感兑现、结尾满意度、是否烂尾。
| 分档 | 特征 |
|---|---|
| 9–10 | 拿起来放不下，无理解障碍，收尾令人满意 |
| 7–8 | 顺畅好读，个别章节想跳 |
| 5–6 | 能读，但需要耐心；中段有明显想弃书区 |
| 3–4 | 阅读负担重，容易弃 |
| 1–2 | 无法读下去 |

## 二、总分与排序（双轨制：模型自评 + 外部共识）

### 2.1 双轨结构（用户要求：不能只靠网站评论，必须结合大模型自身评价）

每个维度都要有**两个分数**：

| 轨道 | 来源 | 角色 | 要求 |
|---|---|---|---|
| **模型自评分**（主） | `model-critic` 读完真实正文后的独立判断 | **决定总分与排序** | 每维必须附文本证据（引原文 ≤40 字） |
| **外部共识分**（对照） | `review-miner` 采集的豆瓣/百科/检索共识 | 只作对照与交叉验证 | 必须写清"读者认为…"，不能冒充自评 |

```
总分（主）= 0.25*W自评 + 0.20*C自评 + 0.15*T自评 + 0.15*E自评 + 0.15*P自评 + 0.10*X自评
对照分    = 同公式，代入外部共识分（仅参考，不参与排序）
```

### 2.2 分歧处理（**最重要的规则**）

计算每维 `Δ = |自评分 − 共识分|`：

| Δ | 处理 |
|---|---|
| < 1.0 | 视为一致，标注"自评与共识一致"，可信度高 |
| 1.0 – 1.5 | 在维度行备注"略有分歧"，一句话说明 |
| **≥ 1.5** | **必须单列"分歧说明"**：我的理由（引原文）+ 外部理由（引评论）+ 可能原因 |

**严禁**：
- ❌ 把两个分数平均成中间值（等于既不信自己也不信读者）
- ❌ 因为外部差评就偷偷把自己的高分改低（或反之）——这叫迎合
- ❌ 只报一个分数，不说明它来自自评还是共识

**为什么保留分歧**：分歧本身就是决策信息。
例：自评文笔 9 但豆瓣说"文笔干瘪" → 说明这本书文笔**风格化、非大众口味**，
用户若喜欢这种风格会很喜欢，若不喜欢会读不下去。这比给个 7.5 有用得多。

### 2.3 排序与偏好重排

- 保留 1 位小数。**排序用自评总分**，但报告必须同时给分项 + 共识对照。
- 若用户明确偏好某维度（"我只要文笔好的"）→ 提供"按偏好单维重排"的第二套排序，
  而非替换默认排序。
- 若某本书外部共识分明显高于自评分（如豆瓣 8.9，自评 7.0）→ 必须在推荐语里提示
  "大众口碑好于我本次抽样的判断"，并说明可能是抽样不足。

## 三、质量门槛（"质量不能太低"的硬线）

推荐给用户的候选书必须**同时**满足：

1. **豆瓣评分 ≥ 7.0**，且**评分人数 ≥ 100**（防止小样本刷分）。
2. 专业/长期口碑不出现**系统性差评集中的硬伤**（如"烂尾""抄袭""设定崩坏"在短评里高频出现）。
3. 有可核查的真实存在性（作者、平台或出版社、ISBN/书号之一能对上）。

> ⚠️ **门槛只管"要不要进候选池"，不管"自评打几分"**。
> 一本书豆瓣 8.9 但你自己读完只给 6.5 → 如实给 6.5 并说明分歧，不要因为门槛/名气往上凑。
> 反之，冷门书只要质量过硬，自评该高就高。

**网文特别条款**（豆瓣评分对网文不友好，常偏低或缺失）：
- 豆瓣分缺失时 → 改用 **平台推荐票/收藏量 + 完本状态 + 章节结构** 三重旁证，
  且必须在报告里明示"该书无豆瓣评分，质量判断依赖平台数据与评论共识，置信度中等"。
- 若三者皆无 → 降级为"信息不足候选"，**放进备选区而不是主推荐区**。

**去重条款（排序前必做）**：同一本书的多个豆瓣版本（初版/再版/分卷/套装）必须归并为 1 条，
取**评分人数最多**的版本作代表。实测例：《诡秘之主》`#33424453` 8.7(15266) 与 `#35051813` 8.5(2731)
是同一本书 —— 当成两本排序会让榜单注水、并让用户误以为有两个选择。

## 四、防"看起来很像真的"的规范

- 分项评语里**引用原文片段时必须是本次真实抓到的句子**，一字不改；字数 ≤ 40 字。
- 无法引用时，写"未取得原文，以下判断基于外部评论共识"。
- 不写"作者显然想表达……"这类无法证伪的揣测；改写"从 N 条评论看，读者普遍认为……"。
- 分数之间要有区分度：如果 5 本书全是 8.2/8.3/8.4，说明量表没用起来 → 重评。
