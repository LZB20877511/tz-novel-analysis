# 输出模板（Lead 汇总时必须套用）

## 模板一：单书深度分析（用户给了书名）

```markdown
# 《书名》· 阅读分析报告
> 分析日期 | 版本 | 作者｜平台｜状态（完本/连载）｜总字数

## 0. 一句话结论
（≤40 字，回答"这本书值不值得我读、适合什么样的人读"）

## 1. 类型定位
- **官方分类**：玄幻 · 异世大陆（起点官方）| 豆瓣标签
- **实质类型**：混合了 A（主线）+ B（元素）+ C（气质）  ← 不要照抄官方分类，要给真实类型判断
- **题材坐标**：[] 与哪些经典作品同族，但差异在哪
- **目标读者**：适合 X 类读者；不适合 Y 类读者（写清楚排斥人群）
- **阅读门槛**：低/中/高 + 原因（设定密度、名词量、开篇节奏）

## 2. 内容简介（不剧透版）
（≤120 字。只写开局处境 + 主角困境 + 类型气质。中段发展与结局一律不写。
 若确实无法在不剧透的前提下写简介，直接写"为避免剧透，本节省略"。）

## 3. 文笔与文风
- **我的判断**（1-2 句，必须有具体依据）
- 句法特征：平均句长 / 长短句节奏 / 对话与叙述比例
- 用词倾向：高频词、是否套语化、是否有个人印记
- **原文取样**：「逐字摘录 ≤40 字」
- **读者怎么说**：（引 1-2 条短评，标注共识/个别）
- 评分：自评 W = N/10　|　共识 X.X　|　Δ=…　依据:真实正文

## 4. 人物与事物描写
### 人物
- 主角：立不立得住、动机是否自洽、有无成长弧（**我的判断**）
- 配角：是否有独立动机（关键判据：离开主角视线后是否还活着）
- 反派：是否可理解
- 读者共识：（如"配角工具人"出现 N 条）
- 评分：自评 C = N/10　|　共识 X.X　|　Δ=…
### 事物/场景/设定
- 场景描写：五感使用、画面感
- 设定：自洽度、是"用出来"还是"讲出来"
- 名词密度与阅读负担
- 读者共识：
- 评分：自评 T = N/10　|　共识 X.X　|　Δ=…

## 5. 感情描写
- 情感线类型与占比（爱情/亲情/友情/信念）
- 是否"写出来"而非"说出来"
- 打动点（不剧透前提下的类型化描述，如"有一段关于父子关系的处理很克制"）
- 读者共识：
- 评分：自评 E = N/10　|　共识 X.X　|　Δ=…

## 6. 情节节奏与结构
- 结构：总 N 章 = 可读 A + 不可读 B；分卷结构
- 张弛：开局/中段/后期的节奏表现
- 伏笔与回收
- 读者共识（含"烂尾"类检索结果）：
- 评分：自评 P = N/10　|　共识 X.X　|　Δ=…

## 7. 阅读体验与数据
| 指标 | 数值 |
|---|---|
| 豆瓣评分 | X.X（N 人，截至日期）|
| 想读/在读/读过 | |
| 总字数 / 章数 | |
| 平台推荐票 | |
| 主要缺陷（评论共识） | |
| 结局满意度 | |

- 评分：X = N/10

## 8. 综合评分与建议（双轨）
**模型自评（主，决定排序）vs 外部共识（对照）**

| 维度 | 权重 | 模型自评 | 外部共识 | Δ | 加权 |
|---|---|---|---|---|---|
| 文笔文风 W | 0.25 | | | | |
| 人物描写 C | 0.20 | | | | |
| 事物描写 T | 0.15 | | | | |
| 感情描写 E | 0.15 | | | | |
| 情节节奏 P | 0.15 | | | | |
| 阅读体验 X | 0.10 | | | | |
| **总分** | 1.00 | **X.X** | X.X（仅参考） | | |

### 8.1 我的独立判断（模型自评，必须写）
- 最打动我的：…（说清哪段、为什么，引原文 ≤40 字）
- 最出戏的：…（哪个设定/写法让人跳出）
- 我会不会推荐给朋友：会 / 不会 —— 一句理由

### 8.2 与读者共识的对照
- 一致的维度：…
- **分歧的维度（Δ≥1.5 必须展开）**：
  - 分歧点：…
  - 读者理由：「…」（引自 N 条评论）
  - 我的理由：「…」（引自原文）
  - 可能原因：读者群体偏好 / 我只读了抽样章节 / 该书前后期水准变化 / …
- 互补（读者提到我漏掉的）：…

> ⚠️ 若本节缺失或只是复述豆瓣 → 报告不合格。用户明确要求"结合大模型自身评价"。

- 一句话推荐：读 / 谨慎读 / 不推荐，理由
- 如果只读一个片段就看这段：第 N 章（说明为什么代表全书水准）
- 弃书预警：最容易弃书的位置 + 是否值得撑过去

## 9. 本次取证覆盖度（必须写，不得省略）
- 真实正文：已读 N 章（第 a-c、x-y 章），共 M 字，占全书 Z%
- 章节结构：已取得全 N 章标题（来自目录页）
- 外部共识：豆瓣短评 M 条（星级分布）、长评 K 篇、百科
- **未覆盖**：VIP 章节正文（X 章）→ 该部分判断依据为章节标题 + 评论共识，置信度中
- **自评置信度**：对前/中/后期质量的把握分别：高/中/低（因抽样章数不同）
- 数据源状态：🟢 全部可用 / 🟡 部分降级（注明）
```

## 通用写作规范（所有模板适用）
1. **结论先行**：每节第一句就是判断，不是铺垫。
2. **可数不用形容词**：写"平均句长 28 字、对话占 41%"，不写"文笔精炼"。
3. **每条判断带证据标签**：`依据:真实正文 / 章节标题 / 外部共识 / 不可得`。
4. **必须留缺陷**：只写优点的报告视为不合格。
5. **剧透零容忍**：见 `agents/spoiler-guard.md`。
6. **覆盖度不藏**：读了 3 章就说 3 章，不要说"通读全书"。
7. **评价双轨必写**（用户明确要求）：
   - 必须有**模型自评**（我读完的真实判断，含主观感受："最打动我的是…"）；
   - 必须有**外部共识对照**（读者怎么说，标注共识/个别）；
   - 分歧 Δ≥1.5 必须展开，**禁止平均抹平**。
   - ❌ 只有豆瓣引用、没有"我认为" → **不合格**。
   - ❌ 有"我认为"但没有原文佐证 → 也算不合格（那是空口评价）。
8. 不写"总体来说是一部值得一读的作品"这类零信息量套话。
