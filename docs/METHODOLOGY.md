# 方法论

> 这些规则不是设计出来的，是**踩坑之后写下来的**。
> 每一条背后都有具体的失败案例。

---

## 一、两条铁律

### 铁律① 事实不许编，评价必须给

这两层要分清，很多人会搞混：

| 层 | 内容 | 规则 |
|---|---|---|
| **事实层** | 情节、人物行为、章数、字数、评分数字 | **必须有真实来源**。禁止凭记忆编造。 |
| **评价层** | 文笔好不好、人物立不立得住、值不值得读 | **必须给出自己的判断**，且必须引真实文本佐证 |

- ❌ "根据我对这本书的了解，主角后来……" —— **编情节，违规**
- ❌ 只把豆瓣短评重新组织一遍 —— **没有自己的判断，失职**
- ✅ 读完正文后给出自己的评分与理由，并引用原文
- ✅ 外部共识作为**对照并列呈现**；一致写一致，分歧写分歧

> 一句话：**情节"我记得"是违规，评价"我认为"是本职。**

### 铁律② 覆盖度必须披露

每次给结论，必须写清：真实读了哪些章、共多少字、占全书百分比；
哪些部分只是靠目录标题 / 评论共识推断。

**禁止说"通读全书"**，除非真的读完了。

"读了 5 章但覆盖了全书结构"是诚实的；"读了 5 章说读完 1000 章"是欺骗。

## 二、双轨评价：为什么必须有两轨

### 只有外部评论 = 复读机

豆瓣、优书网上的评价是**别人的看法**。直接转述，等于把"二手信息"当"分析结论"。

### 只有模型自评 = 没有对照

模型可能读漏、误判、被抽样偏差影响。没有外部对照，就不知道自己的判断偏离多少。

### 所以必须双轨，且顺序不能颠倒

```
第一步：只读正文，独立形成判断（不看任何外部评论）
第二步：再看外部共识，逐维对照
第三步：分歧 ≥1.5 分 → 单列"分歧说明"，禁止取中间值
```

**顺序为什么重要**：如果先看评论，自评会退化成"复读+微调"，这个环节就白做了。

### 分歧本身就是价值

> 自评文笔 6.5，外部说"文笔垃圾" → 不是取中间值 4.5，
> 而是说明：**这本书的文笔风格化、非大众口味。合口味的人会喜欢，不合的读不下去。**

这比给一个 4.5 分有用得多。

## 三、尺度选择：为什么不能一个尺子量所有书

实测教训：用仙侠爽文的尺子量军事文，会得出"冲突密度不足"的错误结论。

| 题材 | 该重点看什么 | 不该用 |
|---|---|---|
| 仙侠/玄幻爽文 | 爽点密度、升级曲线、战力体系 | 文学性、现实主义逻辑 |
| 军事文 | 专业感、战术逻辑、军人气质 | 爽点密度（那会毁掉它） |
| 轻小说/幽默 | 笑点密度、梗是否刷新、喜剧是否降级 | 战力体系严谨度 |
| 文学向 | 句子质量、意象、留白 | 节奏快慢、爽感 |

**结论**：每个维度评分前，先问"这类书的标准是什么"。

## 四、舆论不是一个分数，是地形

详见 [`优化_02_舆论冲突图谱.md`](../data/优化_02_舆论冲突图谱.md)。

核心：**不要压缩舆论，要画出对立结构。**

五种冲突形态，处置完全不同：

| 形态 | 例子 | 处置 |
|---|---|---|
| **A 层次错位** | 夸典故学养 vs 批字句基本功 | 分层陈述，两者都对 |
| **B 人群分裂** | 豆瓣 7.2 vs 优书网 4.5 | 并列，说明是不同人群 |
| **C 时间漂移** | 早期好评 vs 近年差评 | 标时间窗 |
| **D 幸存者偏差** | 分卷递增，但人数只剩 27% | 用人数解释，不用分数 |
| **E 真·两极** | 仙草 443 vs 毒草 442 | 直接告诉用户"这是两本书" |

**必答的一句**：读得下去的人特征是什么，读不下去的人特征是什么。

## 五、证据链可信度

详见 [`优化_03_证据链可信度.md`](../data/优化_03_证据链可信度.md)。

按"由几类**独立**证据支撑"分级，不按"证据条数"：

```
E4  多源交叉且一致      （正文 + 外部共识 + 量化 + 作者自述）
E3  双源可对撞          （自评 vs 外部，能算出 Δ）
E2  单源有据可复核      （只有评论，但有逐字原文）
E1  单源无据            （禁止使用）
E0  不可得              （必须显式列出缺口及影响方向）
```

**总分可信度 = 各维最低**，不是平均。
因为用户看总分时会以为全都验过了。

## 六、数据口径（七条防错规则）

这些都是真实踩过的坑：

| 口径 | 规则 | 踩坑案例 |
|---|---|---|
| **豆瓣多条目** | 分卷/套装/再版**不可相加/平均/相减** | 《大王饶命》13 卷分数各不相同 |
| **短评均值 ≠ 官方分** | 短评常比官方低 0.8–1.0 | 《弹痕》差 1.0 |
| **优书网单条星级** | 是占位图（差评也显示 5 星），**只引聚合** | 实测多次 |
| **改编条目** | 动画/漫画/影视**严禁当原著数据** | 《大王饶命》动画 6597 人 vs 小说 1199 人 |
| **章数口径** | "目录条目数"≠章节数（混有作者话） | 《大王饶命》1363 条 = 1329 正文 + 34 其他 |
| **缺章判定** | 连号核验 → pageId 断号探查 → 才判真缺章 | 《弹痕》"缺章"实为标注 bug |
| **脏文本四分类** | PUA / latin / U+FFFD / 错别字 | 前三种是源站问题，**最后一种是作者问题** |

### 脏文本四分类（关键）

| 类型 | 判据 | 是不是作者问题 |
|---|---|---|
| PUA 私有区码 | `pua` 高 | 否，源站字体加密 |
| 拼音替换 | `latin` 高（如 `sè`=色） | 否，源站替换 |
| 编码错乱 | `U+FFFD` 高 / 首行乱码 | 否，**抓取 bug，必须重抓** |
| 错别字 | 人工判（如「名子」=名字） | **是，作者问题，计入文笔分** |

**前三类不能用来扣作者的分。第四类必须扣。**

## 七、防剧透：硬闸门

用户明确要求：内容简介尽量简单、不剧透；涉及剧透的部分宁可省略。

| 不可写 | 安全改写 |
|---|---|
| "主角最后牺牲了" | 删 |
| "XXX 其实是反派" | 删 |
| "真相是整个村子都是幻觉" | "故事在后期展开了一个较大的设定反转" |
| "第 N 卷女主黑化" | 删 |
| "两人最终成婚" | "感情线贯穿全书" |

**判定标准**：假设读者只看了你的简介，读到全书 1/3 处时，是否会因为简介而失去悬念？
会 → 就是剧透。

## 八、已知的系统性偏差（写给未来的自己）

连续多本书实测，有几个偏差会**稳定复现**：

1. **高估"读者会不会讨论结局"** —— 实测多本书结局取证空白。一旦取证丰盛，反而说明真有问题
2. **低估"反派/配角智力水位"这类批评** —— 容易当类型惯例放过
3. **文笔分常比读者高 1–2 分** —— 可能是真实判断，也可能是宽容偏差。要自问"我是不是在替作者找补"
4. **把"一件事的两面"当两个发现** —— 如"伏笔好 + 冲突零"其实是同一结构，会虚增维度分
5. **量化指标选择性报告** —— 只报对自己论点有利的那组
6. **把抽样说成趋势** —— 3% 覆盖说成"全书唯一"

## 九、为什么不做"一句话推荐"

因为**一本书对不同人的价值是不同的**。

同一本《茅山后裔》：
- 喜欢考据、能忍慢热 → 值得读
- 要一口气停不下来 → 中段就会放下
- 要文笔流 → 会失望

所以本项目要求：
- **必须写缺陷**（只写优点视为不合格）
- **必须写适合谁、不适合谁**
- **必须写弃书预警**（最容易在哪里放下）
